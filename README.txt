NEXTAG WEBSITE – UPDATED VERSION

IMPORTANT CHANGE:
All 20 product cards are written directly in HTML:
- purses.html contains 10 purse cards.
- wallets.html contains 10 wallet cards.
No product cards or product data are generated from JavaScript.

JavaScript is only used for simple interactions:
- Mobile navigation menu
- Brand filter and search
- Product comparison
- Contact form validation

HOW TO EDIT A CARD:
1. Open purses.html or wallets.html in a code editor.
2. Find the product card section (each starts with <article class="product-card">).
3. Edit the product name, brand, category, price and description directly in that card.
4. Each card links to its own Word document in the docs folder.

DESIGN:
- 20 cards total: 10 purses + 10 wallets.
- 4 cards per row on desktop, 3 on medium screens, 2 on tablets and 1 on small phones.
- No product photos are included. Product visuals are CSS-only placeholders.
- Navbar logo is created with HTML/CSS.
- Browser tab icon is favicon.svg.
- Marquee announcement is above the navbar.
